Chinese Clinical Grammar Rules (Session #3 Slide 3)

Core sentence structures used across medical history taking

1. Time When Structure (Time before or after Subject)
Subject + Time (when) + Verb + Object OR Time (when) + Subject + Verb + Object
Example: 我早上九点会去看医生。 (Wǒ zǎoshang jiǔ diǎn huì qù kàn yīshēng.)
"I will see the doctor at 9am."
2. Time When + Location Structure
Subject + Time (when) + Location + Verb + Object
Example: 我礼拜五在医院看病人。 (Wǒ lǐbài wǔ zài yīyuàn kàn bìngrén.)
"I see patients in the hospital on Friday."
3. Time Duration Structure (After Verb)
Subject + Verb + Time (Duration)
Example: 我讲了三个小时。 (Wǒ jiǎngle sān gè xiǎoshí.)
"I talked for 3 hours."
4. Giving Directions (Spatial Location)
Subject + 在 + Direction
Example: 医院在左边。 (Yīyuàn zài zuǒbiān.)
"The hospital is on the left."
